# EfficientAD & CNN Resources

## Knowledge

- [Paper: _EfficientAD: Accurate Visual Anomaly Detection at Millisecond-Level Latencies_ — Batzner et al. (WACV 2024)](https://arxiv.org/abs/2303.14535)
  Original paper. Use for: architecture overview, benchmarks, design rationale. Read after completing the lesson series for deeper understanding.

- [Interactive: _CNN Explainer_ — Georgia Tech / Polo Club](https://poloclub.github.io/cnn-explainer/)
  Visual, interactive browser tool showing convolutions, activations, and feature maps step-by-step. Use for: building intuition about what each CNN layer does to an image. Excellent for beginners.

- [Book: _Dive into Deep Learning_ — Zhang, Lipton, Li, Smola](https://d2l.ai/chapter_convolutional-neural-networks/index.html)
  Free interactive textbook. Chapters 6–8 cover CNNs. Use for: deeper reference on convolution math, padding, stride, pooling. Consult when a lesson's explanation isn't enough.

- [Video: _But what is a convolution?_ — 3Blue1Brown](https://www.youtube.com/watch?v=KuXjwB4LzSA)
  Classic animated explanation of the convolution operation. Use for: understanding the core operation visually before reading the math.

- [Course: _CS231n: Convolutional Neural Networks for Visual Recognition_ — Stanford](https://cs231n.github.io/)
  Full university course, slides and notes available freely. Use for: deep reference on CNN architectures, backprop, training. The 2017 version is particularly well-documented.
